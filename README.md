# agent-company

An experimental starting point for AI-assisted projects: portable working
instructions, project context, and five optional skills for product design,
website content, interface design, interface critique, and owner feedback.

Agent Company is an early experimental project, public for use and inspection.
External contributions are not currently being accepted.

## Start here

Clone this repository and launch your AI coding agent inside it. Ask:

- “Initialize a new project at `/path/to/project` for [purpose].”
- “Add this foundation to my existing project at `/path/to/project`, preserving
  its instructions and context.”

The agent will inspect the target, create or adapt its instructions and context,
and copy the minimal skills justified by known needs. You can request all skills,
no skills, or specific skills. Setup does not implement your product.

Then open the target directory and start a fresh agent session there. The target
is self-contained; you do not need to keep this checkout available.

Bring your own coding agent. Optional skills require support for the included
`SKILL.md` format. There is no required sequence of roles.

Extracted from the EGTEC project; cross-project portability and effectiveness
remain unproven.
